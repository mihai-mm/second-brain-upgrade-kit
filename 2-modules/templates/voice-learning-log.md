# Voice learning log

One entry for every correction the person makes to a draft. Newest on top. This file collects cases before they become rules: nothing here changes the style file by itself.

## Scope values

- **this text only**: the correction depends on this recipient, occasion or fact.
- **this kind of text**: it may apply to the same kind of text. Add it to the routing table or the samples only if it repeats.
- **always**: the person declared it general, or it repeated in at least two independent contexts with no clear counterexample. Propose it for the style file; it enters only after the person confirms.

## Entry format

```
### [YYYY-MM-DD] - [kind of text] to [recipient]

- What I wrote: [the passage, verbatim]
- What the person changed: [the passage after the change, verbatim]
- Reason given by the person: [their words, or "not stated"]
- Rule learned: [one sentence, or "none"]
- Counterexamples looked for: [samples where the opposite holds, or "none found"]
- Scope: [this text only / this kind of text / always]
- Status: [local / candidate / promoted to the style file on YYYY-MM-DD / rejected]
```
