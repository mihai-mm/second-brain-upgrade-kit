# Automated email

Example tool file. What was learned using automated email sending on real work. To read before building or changing a send.

## Mistakes not to repeat

- **2026-10-13** The first trial send went out with the client's name all in capitals, because that is how it was written in the export. Cause: the data was used as it arrived. Instead: check how name and amount look on five rows before every send.
- **2026-10-08** A draft contained the due date in the American format. Cause: format left at the default value. Instead: write the date in full, with the day and the month in words.

## Ways of working that hold up

- **2026-10-13** Before a send to a list, send the same message to yourself with the data of the first and the last row. Applies when: the data comes from an export made by others.

## Verified limits

- **2026-10-13** Client replies arrive in the mailbox the send comes from: if nobody reads it, they stay there. Verified during the trial.
