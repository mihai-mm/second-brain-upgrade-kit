What was learned about each tool lives in `agent/knowledge/tools/`, not in this index. This is only the pointer, so the lessons are found when a tool comes up.

- [Automated email](../agent/knowledge/tools/automated-email.md) - open before building or changing a send, and before a trial send to a list.
- [Spreadsheet exports](../agent/knowledge/tools/spreadsheet-exports.md) - open before using an export made by a client as the source of a count or a send.

**Why:** a cluster of lessons about one tool is a method, not a correction. Keeping the lessons in one file per tool, with one pointer here, keeps the index short. The earlier lines in this index about test sends and about dates stay here because they are triggered by a phrase of Livia, not by a tool.

**How to apply:**
- When the task involves one of these tools, open its file before starting and say so.
- When you learn something new about a tool, add it to its file with the date, not here.
- When a third tool file appears, add one line to this note and not a new line to the index.
