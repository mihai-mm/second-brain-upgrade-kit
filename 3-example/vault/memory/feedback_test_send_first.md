Before any automatic send to a list of clients, send the same message to Livia herself, filled in with the data of the first and the last row. Look at name, amount and date as the recipient will see them.

**Why:** 2026-10-13. The first reminders of the twenty-client trial went out with the client's name in capitals, as it was written in the export. The message was polite and correct, but it looked like shouting. Ottavio Calvesi saw it in the firm's mailbox, because the replies and the sent copies arrive there. A test to herself would have shown it in ten seconds.

**How to apply:**
- Use the first and the last row: they are the ones most likely to be different.
- Check five rows of the export by eye first. See [automated email](../agent/knowledge/tools/automated-email.md).
- Do not send to the list until Livia has read the test message and said yes.
